# Privacy Policy — versão inicial de desenvolvimento

Esta versão do Kazer Universal é um projeto em desenvolvimento. A aplicação possui infraestrutura de autenticação e banco preparada pelo template, mas não define ainda uma política de produção completa para dados de clientes.

Antes de disponibilizar o serviço publicamente, o responsável deve documentar: dados coletados, finalidade, base legal, retenção, subprocessadores, transferências internacionais, direitos dos titulares, exclusão de conta, logs, arquivos enviados, telemetria e contato oficial.

Não enviar dados pessoais, secrets, documentos sensíveis ou conteúdo de produção para esta versão sem uma avaliação específica. Providers externos, quando forem conectados, deverão ser exibidos claramente e receber apenas os dados necessários para a tarefa autorizada.

Este documento é técnico e provisório; não substitui uma política jurídica revisada.
