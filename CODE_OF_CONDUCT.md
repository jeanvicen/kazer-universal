# Code of Conduct

A comunidade Kazer deve ser técnica, respeitosa e responsável. Não serão aceitos assédio, discriminação, ameaças, publicação de dados pessoais, inclusão de secrets ou tentativa deliberada de burlar licenças e controles de segurança.

Contribuições devem discutir o código e o impacto técnico, não atacar pessoas. Mantenedores podem editar, rejeitar ou remover conteúdo que viole esta regra ou coloque usuários, autores de terceiros ou o projeto em risco.

Para reportar uma situação, use um canal privado do repositório. Um e-mail público ainda não foi definido e não deve ser inventado.
