# Referência de direção de produto

A página oficial consultada foi https://hermes-agent.nousresearch.com/ em 12 de setembro de 2026.

Ela apresenta o Hermes Agent como um agente open source/self-hosted com foco em conexão multiplataforma, memória persistente, automação agendada, delegação para subagentes, pesquisa/browsing e sandbox isolado. A direção adotada no Kazer usa apenas esses princípios de clareza de produto e organização de capacidades; não copia textos, marca, layout, código ou imagens.

O Kazer mantém identidade própria: Kazer Open Source Universal, control plane de ecossistema, paleta preto mineral/ciano/laranja e personagem original de estátua de obsidiana.
